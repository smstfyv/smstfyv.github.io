Server otağı standartları: ofisinizin İT məkanı necə qurulmalıdır

EMSAR SOLUTIONS komandası  ·  8 dəq oxu  ·  4 Mart 2026

Bakıda orta ofis layihələrinin böyük hissəsində server otağı son anda və az diqqətlə qurulur. Qənaət hesablanır — bir neçə kondisioner, divara monte rack, bir neçə kabel. İlk illərdə hər şey işləyir.

Problem 18-24 ay sonra başlayır. Server overheating, kabel xaosu, genişlənmə imkanının olmaması, ölçatanlıq problemi. Hər biri öz xərclərini gətirir — həm dolayı (downtime), həm də birbaşa (yenidən qurma).

Hava dövranı və soyutma

Server otağında temperatur 18-24°C aralığında saxlanılmalıdır. Rütubət 40-60% optimal səviyyədir. Lakin tək kondisioner kifayət deyil — server otağı üçün presizyon kondisioner tələb olunur; bu, sabit temperatur və rütubət saxlamaq üçün hazırlanmışdır.

Kondisioner sayı qaydası: minimum N+1. Yəni cari yükü idarə etmək üçün N kondisioner lazımdırsa, bir əlavə yedək olmalıdır. Bir kondisioner sıradan çıxsa, server otağı dayanmamalıdır.

Elektrik təminatı

UPS (Uninterruptible Power Supply) məcburidir. Cari yükə görə hesablanır, minimum 15-20 dəqiqə backup vaxtı saxlanılır. Daha böyük yedəklik üçün dizel generator əlavə olunur — 8 saat və daha çox avtonom iş üçün.

Elektrik kabelləri ayrı dövrəyə bağlanmalıdır — server otağı normal ofis elektriki ilə eyni xəttə qoyulmamalıdır. Bu, həm təhlükəsizlik, həm də keyfiyyət (gərginlik dalğalanmaları) üçün vacibdir.

Kabel təşkili

"Kabel xaosu" server otağında ən yayılmış problemdir. Hər kabel etiketlənməli, marşrutu sxemə daxil edilməlidir. Patch panel istifadəsi məcburidir — birbaşa serverlərə kabelləri bağlamaq qadağandır.

Kabel kanalları ayrı olmalıdır — elektrik kabelləri və data kabelləri eyni kanaldan keçməsin. Elektromaqnit interferensiya data kabellərində xətalar yaradır.

Fiziki təhlükəsizlik

Server otağı kilidli olmalıdır. Kartlı giriş və ya kombinasiya açar sistemi standartdır. Hər giriş loglanır — kim, nə vaxt daxil oldu.

Yanğınsöndürmə sistemi — su deyil, qaz əsaslı (FM-200 və ya bənzər). Su elektronikanı zədələyir, qaz isə rəsmi cihazları toxunmadan yanğını söndürür.

Genişlənmə imkanı

Server otağı qurulandan dərhal sonra 100% dolu olmamalıdır. Tipik qayda — başlanğıcda 40-50% tutum istifadə olunur, qalan boşluq 5-7 illik genişlənmə üçün saxlanılır. Bu, biznes böyüdükdə yeni server otağı tikməyin qarşısını alır.

Yekun

Düzgün qurulan server otağı 10-15 il problemsiz işləyir. Yarımçıq qurulan otağın illik xərci qurulduğunun 30-40%-nə bərabərdir. EMSAR SOLUTIONS İT həlləri çərçivəsində server otağı dizaynı, quraşdırma və ya mövcud otağın audit xidmətləri təklif edir.

Server room standards: how your office IT space should be set up

EMSAR SOLUTIONS team  ·  8 min read  ·  March 4, 2026

In most mid-size office projects in Baku, the server room is set up at the last minute with little attention. Money is saved — a couple of air conditioners, a wall-mounted rack, a few cables. Everything works for the first few years.

Problems start 18–24 months later. Server overheating, cable chaos, no room to expand, scalability issues. Each comes with its own costs — both indirect (downtime) and direct (rebuild).

Airflow and cooling

Temperature in the server room must be kept between 18–24°C. Humidity of 40–60% is optimal. But a standard air conditioner is not enough — a precision air conditioner is required; it is designed to maintain stable temperature and humidity.

The rule on number of units: minimum N+1. That is, if N units are needed to handle the current load, one additional spare must be present. If one unit fails, the server room must not stop.

Power supply

A UPS (Uninterruptible Power Supply) is mandatory. It is sized for the current load, with a minimum 15–20 minute backup time. For greater redundancy, a diesel generator is added — for 8 hours or more of autonomous operation.

Power cables must be connected to a dedicated circuit — the server room must not share a line with the regular office electrical supply. This is important for both safety and quality (voltage fluctuations).

Cable management

"Cable chaos" is the most common problem in server rooms. Every cable must be labelled and its route included in the schematic. Patch panel use is mandatory — connecting cables directly to servers is prohibited.

Cable conduits must be separate — power cables and data cables must not run through the same conduit. Electromagnetic interference causes errors in data cables.

Physical security

The server room must be locked. A card-access or combination lock system is standard. Every entry is logged — who entered and when.

Fire suppression — not water-based, but gas-based (FM-200 or equivalent). Water damages electronics; gas extinguishes the fire without touching the equipment.

Scalability

The server room must not be 100% full immediately after being set up. The typical rule — 40–50% capacity is used at the start, and the remaining space is reserved for 5–7 years of expansion. This prevents having to build a new server room as the business grows.

Summary

A properly built server room runs without issues for 10–15 years. The annual cost of a poorly built room equals 30–40% of what it cost to build. Within EMSAR SOLUTIONS IT services, we offer server room design, installation, and audits of existing rooms.

Стандарты серверной комнаты: как должно быть организовано ИТ-пространство вашего офиса

Команда EMSAR SOLUTIONS  ·  8 мин чтения  ·  4 марта 2026

В большинстве офисных проектов Баку серверная комната создаётся в последний момент и без должного внимания. Экономят на всём — несколько кондиционеров, стойка на стене, пучок кабелей. Первые годы всё работает.

Проблемы начинаются через 18–24 месяца. Перегрев серверов, кабельный хаос, отсутствие возможности расширения, проблемы с масштабируемостью. Каждая из них влечёт затраты — как косвенные (простои), так и прямые (перестройка).

Вентиляция и охлаждение

Температура в серверной комнате должна поддерживаться в диапазоне 18–24°C. Оптимальный уровень влажности — 40–60%. Однако обычного кондиционера недостаточно — для серверной требуется прецизионный кондиционер, разработанный для поддержания стабильной температуры и влажности.

Правило по количеству кондиционеров: минимум N+1. То есть если для управления текущей нагрузкой требуется N кондиционеров, необходим один дополнительный резервный. При выходе из строя одного кондиционера серверная не должна останавливаться.

Электроснабжение

ИБП (источник бесперебойного питания) обязателен. Рассчитывается по текущей нагрузке, минимальное время резервного питания — 15–20 минут. Для большей автономности добавляется дизельный генератор — для работы 8 часов и более.

Электрические кабели должны быть подключены к отдельной цепи — серверная не должна находиться на одной линии с обычной офисной электросетью. Это важно как для безопасности, так и для качества электроснабжения (скачки напряжения).

Организация кабельной инфраструктуры

«Кабельный хаос» — наиболее распространённая проблема в серверных комнатах. Каждый кабель должен быть промаркирован, а его маршрут внесён в схему. Использование патч-панели обязательно — прямое подключение кабелей к серверам недопустимо.

Кабельные каналы должны быть раздельными — электрические и информационные кабели не должны проходить по одному каналу. Электромагнитные помехи вызывают ошибки в информационных кабелях.

Физическая безопасность

Серверная комната должна быть заперта. Стандартом является система доступа по карте или комбинированный замок. Каждый вход фиксируется в журнале — кто и когда входил.

Система пожаротушения — не водяная, а газовая (FM-200 или аналогичная). Вода повреждает электронику, тогда как газ тушит пожар, не затрагивая оборудование.

Возможность масштабирования

Серверная комната не должна быть заполнена на 100% сразу после ввода в эксплуатацию. Типовое правило — в начале используется 40–50% ёмкости, остальное резервируется для расширения на 5–7 лет. Это позволяет избежать строительства новой серверной по мере роста бизнеса.

Итог

Правильно построенная серверная комната работает без проблем 10–15 лет. Ежегодные расходы на обслуживание неправильно построенной серверной составляют 30–40% от первоначальных затрат на её создание.
